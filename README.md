# Análisis Exploratorio de Datos - Vehículos en Venta

## 📌 Descripción del Proyecto

Esta aplicación web fue desarrollada con **Streamlit** como parte del proyecto de análisis exploratorio de datos.

El objetivo es visualizar información del dataset `vehicles_us.csv`, que contiene anuncios de venta de vehículos en Estados Unidos.

La aplicación permite generar visualizaciones interactivas para analizar:

- Distribución del kilometraje (odómetro)
- Relación entre precio y kilometraje

---

## 📊 Funcionalidades

- Visualización opcional de los primeros registros del dataset
- Histograma del odómetro
- Gráfico de dispersión: Precio vs Odómetro
- Interfaz interactiva con botones
